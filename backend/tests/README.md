# 测试运行说明

Jest 通过 `ts-jest` 加载 `backend/src/**/*.ts`，测试不得再导入根目录下已废弃的同名 JavaScript 实现。

## 测试文件结构

```
tests/
├── setup.js           # 测试环境设置
├── unit/             # 单元测试
│   ├── user.test.js   # 用户路由测试
│   ├── novel.test.js  # 小说路由测试
│   └── ai.test.js     # AI 路由测试
├── integration/       # 集成测试
│   └── app.test.js    # 应用集成测试
└── simple.test.js     # 简单测试示例
```

## 测试内容

1. **单元测试**：
   - 用户路由：注册、登录、获取用户信息、更新用户信息、修改密码
   - 小说路由：创建小说、获取小说列表、删除小说、创建章节、获取章节列表、更新章节顺序、删除章节、更新章节标题
   - AI 路由：生成章节、续写章节、内容润色、生成设定、生成大纲、生成创意

2. **集成测试**：
   - 完整的用户流程：注册、登录、获取用户信息
   - 完整的小说流程：创建小说、获取小说列表、创建章节、获取章节列表
   - AI 功能测试：生成章节、润色内容
   - 健康检查

## 运行测试

可以使用以下命令运行测试：

```bash
# 运行所有测试
npm test

# 运行单元测试
npm run test:unit

# 运行集成测试
npm run test:integration

# 运行测试并生成覆盖率报告
npm run test:coverage

# 排查异步资源或数据库连接未关闭的问题
npm test -- --runInBand --detectOpenHandles
```

## 测试覆盖率目标

- 分支覆盖率：50%
- 函数覆盖率：50%
- 行覆盖率：50%
- 语句覆盖率：50%

## 注意事项

1. 测试文件使用了 mock 来模拟数据库、Redis 和 AI 服务，避免实际调用外部服务
2. 测试覆盖了主要的功能和错误场景
3. 测试代码遵循 Jest 测试框架的最佳实践

## 错误处理和代码注释

除了测试文件外，项目还添加了完善的错误处理和代码注释：

1. **错误处理**：
   - 全局错误处理中间件
   - 详细的错误日志
   - 统一的错误响应格式
   - 输入验证和参数校验

2. **代码注释**：
   - 函数和方法的文档注释
   - 关键逻辑的中文说明
   - 复杂算法的解释
   - 配置项的说明

这些测试文件和错误处理机制确保了项目的质量和可靠性，为后续的维护和扩展提供了良好的基础。
